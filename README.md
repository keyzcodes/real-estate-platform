# Real Estate Platform

A transparent real-estate marketplace connecting property seekers directly with landlords, caretakers and transparent agents.

## Problem

Property seekers often experience:

- Hidden or inflated agent fees
- Misleading property information
- Inaccurate locations
- Outdated availability
- Undisclosed additional charges
- Difficulty inspecting properties remotely

## Solution

The platform will provide:

- Verified property listings
- Property photos and videos
- Accurate map locations
- Clear provider identification
- Complete rent and fee breakdowns
- Total move-in cost
- Direct provider contact
- Inaccurate-listing reports

## Phase 1 MVP

The first release will focus on property discovery around UNIMAID and Maiduguri.

### Visitor Features

- Browse property listings
- Search and filter properties
- View property details
- View photos and videos
- View maps and distance information
- See rent and additional fees
- Contact the responsible provider
- Report inaccurate information

### Administrator Features

- Create and edit properties
- Create property units and listings
- Add prices and additional fees
- Upload property media
- Add map locations
- Verify property information
- Publish or archive listings
- Review inquiries and reports
